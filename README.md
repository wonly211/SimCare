# 简护 | Simcare

给家人的健康记录本。一个家庭共用一个实例，最多 10 位成员，可记录血压、心率、血氧、体温和用药计划，查看趋势，并在断网时继续记录。

## 在 Cloudflare 安装

目标流程无需本地命令行：

1. 在 Cloudflare **Workers 和 Pages → 创建应用程序** 中连接本 GitHub 仓库，选择 `main` 分支并填写项目名。仓库根目录就是应用目录，无需再填写 `app/`。
2. 保留控制台默认构建、部署命令。项目安装脚本负责构建应用、创建与项目同名的 D1、绑定 `DB` 并执行数据库迁移。
3. 在 Worker **设置 → 变量和机密** 中添加名为 **`init_key`** 的普通变量，填写自己保存的随机字符串并保存。
4. 打开应用，填写手机号、昵称和该初始化密钥，建立家庭。首个用户同时是系统管理员和家庭管理员。
5. 如需自定义域，在 Worker 中添加自定义域，待其生效即可访问，不需要填写域名变量或白名单。

**当前验收状态：本地构建、模拟部署流程及浏览器业务测试已完成；Cloudflare 控制台默认命令安装和真实手机验收尚未完成。** 不能将这份目标流程视为已验证的一键安装承诺。Cloudflare 官方列出的默认 Builds 令牌权限未包含 D1 编辑权限；自动建库和迁移是否能在默认配置下执行尚待实测。若 Builds 未提供所需凭据或权限，安装会明确停止，不会要求把 API token 填入应用变量。

`init_key` 同时用于系统管理员应急登录。无需配置短信服务、密码、Passkey 或 `RP_ID`。兼容旧版大写 `INIT_KEY`；两者同时配置时必须相同。

## 家人如何使用

- 管理员在“家庭成员”生成邀请，将链接或二维码交给家人。
- 家人填写手机号、昵称和设备名称，管理员在“我的账户 → 登录申请”批准。
- 已有成员换设备时输入手机号申请，管理员批准即可。手机号仅作为家庭内部账号，不发送短信、不验证号码真实归属。
- 已批准设备保持登录。联网使用时每天最多续期一次，可保持至最后续期后的 180 天；清除浏览器数据或移除设备后需重新申请。
- 系统管理员使用自己的手机号和当前 `init_key` 登录，不需要其他人批准。

支持中国大陆 11 位手机号，也可以输入 `+86` 前缀。家庭管理员可以批准普通成员；只有系统管理员能批准其他家庭管理员或调整管理员身份。

## 安装到手机桌面

用手机浏览器打开应用，在浏览器菜单中选择“安装应用”或“添加到主屏幕”（具体名称因浏览器而异）。应用完整名称为“简护 | Simcare”，桌面短名称为“简护”。

## 健康与用药

记录支持修正、软删除和历史保留。家庭管理员可查看和照护所有成员；普通成员之间可授予“无权限”“查看”“照护”。家庭用药清单对成员可见。

“今日用药”表示计划，不表示已经服用。应用不提供服药打卡、提醒、医疗诊断或用药建议。时间统一为北京时间。

## 离线与备份

首次登录、设备批准、家庭管理和备份恢复需要网络。已经登录并缓存的数据可离线查看，记录在恢复网络后自动同步，冲突会明确提示。

系统管理员可导出加密备份，也可预览后执行合并或覆盖恢复。离线副本不等于备份；请自行保存备份文件和备份密码。当前备份及恢复前快照各限制为 750 KiB。

恢复会使设备退出登录；系统管理员先用当前 `init_key` 登录，再批准家人设备。新备份包含手机号账号，旧 Passkey 版本备份不支持直接恢复。
